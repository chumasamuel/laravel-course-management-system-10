# Laravel Practical 10 — Course Management System

**Student:** Samuel Fernando Chuma  
**Framework:** Laravel 9  
**Database:** MySQL  
**PHP:** 8.0.30 or newer within PHP 8.x

## 1. What this project contains

This is a complete Laravel CRUD project for Practical 10. It includes:

- `departments` and `courses` database tables
- One-to-many Eloquent relationship: Department → Courses
- Resource routing
- `CourseController` with full CRUD
- Route model binding
- Create, Read, Update and Delete operations
- Server-side validation
- Duplicate course-code prevention
- Foreign-key validation
- Search by course title or code
- Department filtering
- Pagination
- Friendly empty and validation error states
- CSRF protection
- Delete confirmation
- Bootstrap 5 responsive interface
- Seed data with 3 departments and 10 courses

## 2. Requirements

Install these on Windows:

1. PHP 8.2 or newer
2. Composer
3. MySQL 8+ (XAMPP is fine)
4. A browser

Node/NPM is **not required** for this version because Bootstrap is loaded from a CDN.

## 3. Installation

Open Command Prompt inside the project folder.

```text
composer install
```

Create the environment file:

```text
copy .env.example .env
```

Generate the Laravel application key:

```text
php artisan key:generate
```

## 4. Create the MySQL database

Start **Apache** and **MySQL** in XAMPP.

Open phpMyAdmin and create a database named:

```text
course_management
```

The project `.env` is already configured for the common XAMPP setup:

```text
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=course_management
DB_USERNAME=root
DB_PASSWORD=
```

If your MySQL password is different, edit `.env`.

## 5. Create tables and sample data

Run:

```text
php artisan migrate:fresh --seed
```

This creates:

- departments
- courses
- 3 departments
- 10 sample courses

## 6. Start the project

Run:

```text
php artisan serve
```

Open:

```text
http://127.0.0.1:8000
```

## 7. Useful commands

Show Laravel routes:

```text
php artisan route:list
```

Clear configuration cache:

```text
php artisan config:clear
```

Clear application cache:

```text
php artisan optimize:clear
```

Run tests:

```text
php artisan test
```

## 8. CRUD routes

| Method | URL | Action |
|---|---|---|
| GET | `/courses` | List courses |
| GET | `/courses/create` | Create form |
| POST | `/courses` | Store course |
| GET | `/courses/{course}` | Show course |
| GET | `/courses/{course}/edit` | Edit form |
| PUT/PATCH | `/courses/{course}` | Update course |
| DELETE | `/courses/{course}` | Delete course |

These routes are generated using:

```php
Route::resource('courses', CourseController::class);
```
